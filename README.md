# FGO 剧情追剧指南

**在线阅读：<https://cdyforever.github.io/fgo-story-guide/>**

不玩《Fate/Grand Order》，也能靠 B 站视频合集完整看懂这部「人理物语」。

本指南的所有视频链接、分 P 定位、封面与播放数据均通过 Bilibili 开放接口实时抓取校验（2026-08-29），每章一键直达对应视频分 P，部分章节支持页面内直接播放。

## 内容结构

| 章节 | 内容 |
|---|---|
| 三种看法 | 解说精读 / 原版全收录 / 官方动画，三条路线任选 |
| 世界观速览 | 5 分钟看懂迦勒底、特异点、异闻带 |
| 第一部「观测时间之树」 | 序章F + 七大特异点 + 终局，逐章梗概/解说/名场面 |
| 1.5 部亚种特异点 | 新宿、雅戈泰、下总国、SE.RA.PH、塞勒姆 |
| 第二部「Cosmos in the Lostbelt」 | 七大异闻带 + 五个间章 |
| 奏章 | 连载中的终局篇章（更新至奏章IV） |
| 官方动画路线 | 巴比伦尼亚 / 卡美洛 / 所罗门观看顺序 |
| 名场面高光 | 时间紧张时的直跳清单 |

## 本地离线使用

直接双击 `index.html` 也可以看。如果遇到 B 站封面图加载失败（图床防盗链），可以双击 `启动FGO剧情指南.bat`（需 Node.js），它会：

1. 启动本地服务器 `http://127.0.0.1:8765` 并自动打开浏览器；
2. 把所有封面图改走本地代理（自动补 Referer，绕过防盗链并缓存）。
